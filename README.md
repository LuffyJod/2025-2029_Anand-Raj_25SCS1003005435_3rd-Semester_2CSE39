## 💻 Internship Projects

During the internship, I worked on multiple web development projects covering frontend development, backend development, databases, APIs, and real-time communication.

### Tasks Completed

#### Task 1
Basic Web Development project focusing on frontend implementation and responsive design.

#### Task 2 — Employee Management System
A full-stack Employee Management System with:

- HTML, CSS and JavaScript
- Node.js
- Express.js
- MongoDB
- CRUD operations
- Employee search
- Add employee
- Edit employee
- Delete employee

#### Task 3 — Local Store / E-Commerce Website
A full-stack e-commerce application featuring:

- Product listing
- Product search
- Category filtering
- Shopping cart
- Product information
- Node.js and Express.js backend
- MongoDB database
- Responsive frontend

#### Task 4 — Real-Time Chat Application
A real-time chat application developed using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Socket.IO

Features include:

- User registration
- User login
- Real-time messaging
- Multiple users
- Chat rooms
- Message timestamps
- MongoDB message storage
- Persistent message history
- Logout functionality

#### Task 5
Upcoming full-stack web development project.
